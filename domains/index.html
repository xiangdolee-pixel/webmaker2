Cloudflare API 토큰 넣기 처음 한 번만

  1. Cloudflare → 내 프로필 → API 토큰 에서 토큰 생성 → 사용자 지정 토큰.
  2. 이름은 domains.plators.com, 권한은 아래 다섯 줄:
    • 계정 · Workers 스크립트 · 편집
    • 영역(Zone) · 영역 · 읽기
    • 영역(Zone) · DNS · 편집
    • 영역(Zone) · SSL 및 인증서 · 편집
    • 영역(Zone) · Workers 경로 · 편집
